# planner-site

Landing page do Diagnóstico de Crédito da Planner Consultoria, publicada pelo GitHub Pages.

- `index.html`: página principal
- `politica-de-privacidade.html`: política de privacidade (LGPD)
- `assets/css/style.css`, `assets/js/main.js`: estilo e scripts
- `assets/img/`: logo e fotos otimizadas

Checkout: Greenn (produto 155834). O script repassa os parâmetros `utm_*` e `fbclid` da página para o link do checkout.

Pixel da Meta: o código está comentado no `<head>` do `index.html`. Para ativar, troque `SEU_PIXEL_ID` pelo ID do pixel do portfólio Planner Consultoria e remova os comentários.
